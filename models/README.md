# Model nhận diện giọng nói

Thư mục này để trống trên GitHub (file model ~40 MB). Chạy `CAI-DAT.bat` hoặc `setup.ps1` để tự tải:

- `speaker-embedding.onnx` — nhận dạng giọng (3D-Speaker ERes2Net, Apache-2.0)

Nguồn: https://github.com/k2-fsa/sherpa-onnx/releases
